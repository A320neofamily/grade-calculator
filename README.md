# [원점수 계산기 by dohoon 바로가기](https://a320neofamily.github.io/grade-calculator/)
중학교의 원점수를 계산하는 성적 계산기입니다.

## 평가계획과 반영비율을 한눈에

각 학교의 평가계획표를 참고하여, 과목별 지필 · 수행 반영비율을 한눈에 확인할 수 있습니다.

## 미리 계산해보는 성적

자신의 점수만 넣으면, 자동으로 반영비율에 따라 원점수가 계산됩니다.

## 매번 다시 쓸 필요 없이

성적은 사용하는 브라우저의 캐시에 저장되어, 매번 다시 쓸 필요 없이 확인할 수 있습니다.

## 도달할 수 있는 최고 등급까지

지필이나 수행을 하나 남겼다면, 자신이 할 수 있는 가능한 높은 등급을 달성하기 위한 최소 점수를 계산합니다.

## 우리 학교가 없다면

[Instagram @grade.calculator_](https://www.instagram.com/grade.calculator_/)로 해당 학교의 평가계획표나 중학교 이름을 보내주세요.

## 개발방식

Figma Make + Claude를 통해 웹 디자인을 구축하고, Vite React 프로젝트로 기능을 구현했어요.
